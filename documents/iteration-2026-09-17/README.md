## Maintain the documents

Edit [Report_Source.md](Report_Source.md), then run from the repository root:

```powershell
.\backend\.venv\Scripts\python.exe documents/iteration-2026-09-17/build_report.py
```

The generator uses Python's standard library and captured JSON evidence. It does not query a database or run application tests. Do not edit generated formats independently.

`capture_repository.py` can capture source inventories and declared SQLAlchemy metadata using the backend environment. It excludes database contents, installed dependencies, and generated documentation. Recapturing changes the evidence snapshot; update the narrative and rerun relevant checks before describing a later snapshot as verified. Test/build logs are retained from actual commands and are not regenerated by the report builder.
